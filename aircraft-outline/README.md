# Aircraft outline assets

Each aircraft has its own directory. File names use the aircraft code followed by
the view: `front`, `side`, or `top`.

| Directory | Aircraft | Category |
| --- | --- | --- |
| `cessna-172` | Cessna 172 Skyhawk | single-engine piston / high wing |
| `piper-pa-28` | Piper PA-28 Cherokee/Archer | single-engine piston / low wing |
| `cirrus-sr22` | Cirrus SR22 | single-engine piston / composite low wing |
| `cirrus-sf50` | Cirrus Vision Jet SF50 | single-engine personal jet |

`*-3-view.*` files are the complete source sheets. The Cirrus source JPEGs are
retained, and `*-3-view-enhanced.png` is the larger, sharpened working version
used to produce their per-view PNGs. The Cessna source SVG is retained alongside
its rendered PNG sheet.
